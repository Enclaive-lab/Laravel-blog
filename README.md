# Laravel Blog

Учебный блог на Laravel 13 и PHP 8.3+.

## Возможности

- Публичные посты, поиск и пагинация.
- Админка для управления постами и пользователями.
- Регистрация, вход, подтверждение почты и восстановление пароля.
- REST API с токенами Laravel Sanctum и ограничением частоты запросов.
- Мягкое удаление, корзина, восстановление и окончательное удаление постов через API.
- Кеширование списка постов, отдельных постов и корзины.

## Локальный запуск

Нужны PHP 8.3+, Composer и расширение PHP для выбранной базы данных. Команды ниже выполняются в папке проекта; при настройке новой копии используйте отдельную базу данных.

```sh
composer install
php -r "file_exists('.env') || copy('.env.example', '.env');"
php artisan key:generate
```

Настройте подключение к базе в `.env`. Для SQLite, выбранной в `.env.example`, создайте файл:

```sh
php -r "file_exists('database/database.sqlite') || touch('database/database.sqlite');"
```

Для локального кеша без Redis можно указать `CACHE_STORE=file`.

```sh
php artisan migrate
php artisan storage:link
php artisan serve
```

Блог: `http://127.0.0.1:8000/blog`. Админка: `/admin/posts` — доступна авторизованному пользователю с подтверждённой почтой и ролью `admin`. Регистрация сама по себе не выдаёт права администратора.

Основные страницы используют Tailwind CSS через CDN; для них не требуется сборка Vite.

## Почта

По умолчанию `MAIL_MAILER=log`: письма сохраняются в `storage/logs/laravel.log`. Для настоящей отправки настройте SMTP в локальном `.env` и выполните `php artisan config:clear`.

## REST API

- `POST /api/auth/register`, `POST /api/auth/login` — регистрация и получение токена.
- `GET /api/auth/me`, `POST /api/auth/logout` — текущий пользователь и выход.
- `GET /api/posts`, `GET /api/posts/{id}` — опубликованные посты.
- `POST /api/posts`, `PUT /api/posts/{id}`, `DELETE /api/posts/{id}` — создание, изменение и мягкое удаление.
- `GET /api/posts/trashed`, `POST /api/posts/{id}/restore`, `DELETE /api/posts/{id}/force` — корзина, восстановление и окончательное удаление.

Для защищённых запросов передавайте `Authorization: Bearer <token>` и `Accept: application/json`.

## Данные и секреты

В репозиторий не включены `.env`, локальные базы, пользовательские загрузки, логи, кеши, зависимости и рабочие заметки. Они не переносятся при клонировании. `.env.example` содержит только пример настроек.

Проект развивается в рамках обучения; это не готовая конфигурация для публичного сервера. Перед размещением настройте окружение, почту, HTTPS и отключите `APP_DEBUG`.
